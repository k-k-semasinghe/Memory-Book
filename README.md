## What is Memory Book?

Memory Book helps you save and organize important moments, thoughts, reminders, and everyday notes in one place.

The app is currently available for **Android only**. It is an early test version, so some features are still being improved.

## What can I do with it?

- Write and edit personal notes
- Add categories and tags
- Browse notes by date
- Search through your notes
- Keep temporary notes in the Scratchpad
- Move notes to Trash and restore them later
- Set one-time or repeating reminders
- Ask the optional AI assistant questions about your notes
- Get AI suggestions for organizing notes

## Download the Android app

Tap the button at the top of this page to download the latest test APK.

If GitHub shows a warning or Android blocks the installation:

1. Open your phone's browser or file manager settings.
2. Allow that app to install unknown apps.
3. Open the downloaded `memory-book.apk` file.
4. Install Memory Book.

Only install the APK from a source you trust. This is a test build, not a Play Store release.

## First use

1. Open Memory Book.
2. Allow notifications if you want reminders to appear.
3. Tap the **+** button to create your first note.
4. Add a title or message, then save it.
5. Use the tabs at the bottom to browse your Home, Timeline, Search, and Scratchpad.

## Optional AI features

The AI assistant is turned off by default and is not required to use the journal.

To use it, open **Settings > AI assistant**, choose Gemini or Groq, and add your own API key. AI features need an internet connection and may be subject to the provider's costs and rules.

## Your data

- Your notes are saved on your device.
- You do not need an account to use the main journal features.
- AI is optional.
- If you use AI, selected note content may be sent to the AI provider you choose.
- Cloud sync and export/backup are not available yet.
